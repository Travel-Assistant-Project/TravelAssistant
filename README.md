## ✈️ TravelAssistant

**A cross-platform mobile application designed to simplify travel planning and destination exploration.**

TravelAssistant is a React Native application built with Expo, designed to provide users with an intuitive starting point for organizing their travel experiences. The application uses Expo Router for navigation and a modular screen structure to support future feature development.

### Key Components

- **Welcome Screen:** An introductory interface that guides users into the application.
- **Navigation:** File-based routing with Expo Router and a tab-based navigation structure.
- **Modular UI:** Separate screens for Home, Explore, and Profile to organize the application's main sections.
- **Cross-Platform Development:** Built with React Native and Expo for mobile development.

### Technology Stack

- React Native
- Expo
- Expo Router
- TypeScript
- React Navigation

### Getting Started

Clone the repository:

```bash
git clone https://github.com/Travel-Assistant-Project/TravelAssistant.git
cd TravelAssistant
```

Install dependencies and start the development server:

```bash
cd frontend
npm install
npx expo start -c
```

Open the application in an iOS Simulator, Android emulator, or compatible Expo Go environment.
